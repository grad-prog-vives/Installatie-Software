Disable AI in Visual Studio

Microsoft maakt het ons moeilijker en moeilijker om AI niet te installeren op onze computer. Voor permanente evaluatie en voor examens, dient deze echter uitgeschakeld te zijn.

Hieronder de checks die uitgevoerd dienen te worden:

Zorg ervoor dat je Visual Studio in het Engels (of Nederlands) geïnstalleerd hebt staan. Andere talen worden tijdens examens niet aanvaard.

1. Open Visual Studio Installer

  • Open Visual Studio installer vanuit het startmenu:
  • Selecteer de laatste versie en klik op Modify
  • Zoek bij individual components naar Copilot en deselecteer alle vinkjes.
  • Klik op installeren/aanpassen.

2. Controleer

  • Ga naar Tools -> options
  • Type suggestion providers
  • Zie dat enkel intellicode zichtbaar is
  • Voor Jaar 1, Semester 1: Schakel intellicode uit.
    Vanaf Jaar 1, Semester 2: Intellicode mag aangeschakeld staan

3. Verberg de chat

  • Ook al is je Copilot niet geïnstalleerd in visual studio, toch komen soms iconen zichtbaar. Je kan dit uitschakelen in Tools -> option-> zoek copilot -> hide copilot badge.
    Geef eventueel toestemming dat de app wijzingen mag aanbrengen aan het apparaat.
