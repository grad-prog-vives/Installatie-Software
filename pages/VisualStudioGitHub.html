Clonen en pushen met GitHub in Visual Studio

Met Git hou je de versies van je code bij. Op GitHub staat een online kopie van je project: de remote repository. Op je eigen pc werk je in een lokale repository.

In deze handleiding doe je drie dingen:

  • Clone: je haalt een repository van GitHub naar je pc. Dit doe je maar één keer per project.
  • Commit: je bewaart je wijzigingen. Een commit staat alleen op je eigen pc.
  • Push: je stuurt je commits naar GitHub.

1. Link van de repository kopiëren

  • Klik op de link dat je krijgt naar de repository.
  • Klik op de groene knop Code.
    Kies het tabblad HTTPS en klik op het kopieer-icoon naast de link.
  • De link eindigt altijd op .git, bijvoorbeeld https://github.com/grad-prog-bap/oe-Lists.git.

2. Repository clonen in Visual Studio

  • Start Visual Studio. Klik in het startvenster rechts op Clone a repository.
  • Staat er al een project open? Kies dan in het menu Git voor Clone Repository...
  • In het venster Clone a repository:
    • Plak de link bij Repository location.
    • Kies bij Path de map waar het project op je pc komt, bijvoorbeeld C:\Repos\oe-Lists.
    • Klik op Clone.
  • Kies een map buiten OneDrive. OneDrive en Git zitten elkaar vaak in de weg.
  • Krijg je een aanmeldvenster? Kies dan Sign in with your browser en log in met je GitHub-account. Visual Studio onthoudt dit daarna.

3. Solution openen

  • Visual Studio downloadt de bestanden en toont de map in de Solution Explorer.
    Zie je alleen mappen? Dubbelklik dan op het bestand Lists.sln (of Lists.slnx).
  • Rechts onderaan in de statusbalk zie je de naam van de branch, master. Zo weet je dat Git actief is.
  • Een volgende keer open je het project gewoon via Open recent in het startvenster. Je moet niet opnieuw clonen.

4. Wijzigingen committen

  • Pas je code aan en sla op met Ctrl + S.
  • Open het venster Git Changes via View > Git Changes.
    Onder Changes staan de bestanden die je gewijzigd hebt.
    • M = modified (gewijzigd)
    • A = added (nieuw toegevoegd)
  • Typ in het tekstvak een korte boodschap in het Engels, bijvoorbeeld Add Excercise 2 to Readme.md.
  • Klik op Commit All.
  • Je wijziging staat nu alleen op je eigen pc. GitHub weet er nog niets van.

5. Pushen naar GitHub

  • Klik bovenaan in Git Changes op het icoon Push (pijl omhoog).
    Je kan ook in het menu Git kiezen voor Push.
  • Is het gelukt, dan verschijnt de melding Successfully pushed to origin/master.
  • Sneller: klik op het pijltje naast Commit All en kies Commit All and Push. Dan commit en push je in één keer.

6. Controle op GitHub

  • Vernieuw de pagina van je repository op GitHub.
    Bovenaan zie je je naam, je commit-boodschap en now of 2 minutes ago.
