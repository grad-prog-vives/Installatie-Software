Installatie van Visual Studio Code

Visual Studio Code (VS Code) is een lichte, gratis en open‑source code‑editor ontwikkeld door Microsoft.
Het is ontworpen voor snelle, moderne softwareontwikkeling en werkt op Windows, macOS en Linux.
VS Code ondersteunt honderden programmeertalen en biedt krachtige functies zoals AI‑ondersteuning, debugging, Git‑integratie en uitbreidbare extensies.

1. Downloaden van Visual Studio Code

  • Ga naar de officiële Visual Studio Code pagina op VS Code te downloaden.
  • Zoek op de website naar Download for Windows.
  • Het bestand wordt automatisch gedownload en komt in je downloadmap terecht. (VSCodeUserSetup-x64-xxx.exe). Waarbij xxx het versie nummer is (1.140.0 op dit moment).

2. Installatie uitvoeren

  • Open het gedownloade bestand (VSCodeUserSetup-x64-xxx.exe). Waarbij xxx het versie nummer is (1.140.0 op dit moment).
  • Kies Engels als taal van de installatie.
  • Accepteer de gebruikersvoorwaarden
  • Kies een installatielocatie op je computer.
    Standaardlocatie is prima
  • Wanneer je de optie krijgt op VS Code toe te voegen aan het startmenu, voeg dit toe
  • Vink alle opties aan onder Others.
    Dit zorg ervoor dat VS Code gemakkelijk kunt openen en gebruiken
  • Klik op Install om de installatie te voltooien.
  • Na de installatie kan je VS Code openen via het Start Menu of via het bureaublad.
    Of laat het vinkje Launch Visual Studio Code aangevinkt staan.

3. Controle installatie

  • Je krijgt de vraag om in te loggen met GitHub.
    Klik onderaan op Continue without signing in
  • Kies het kleur voor het thema van VS Code.
    en klik op Get Started
  • Als je onderstaand scherm te zien krijgt (of in een ander kleurthema) is alles geïnstalleerd

4. Installatie features

Voor het OPO Frontend Web Development heb je een feature nodig die moet geïnstalleerd worden.
  • Klink links in het menu op het Extensions-icon. De vier blokjes
  • Zoek in het menu naar Live Server van Ritwick Dey.
  • Klik op install om de extensie toe te voegen.
    Deze extensie maakt het mogelijk om je HTML-bestanden live in je browser te bekijken, wat ideaal is voor webontwikkeling.
  • Je zal de melding krijgen of je de publisker vertrouwt.
    Klik op Trust Publisher & Install.

5. AI-features uitschakelen

AI-features zijn verplicht om uitgeschakeld te zijn.
  • Klik op het dropdown menu rechts bovenaan naast de zoekbalk.
    Klik op Learn How to Hide AI Features?
  • Vink Chat: Disable AI Features aan om de AI-features uit te schakelen.
