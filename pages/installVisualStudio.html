Installatie van Visual Studio Community

Microsoft Visual Studio is een uitgebreide ontwikkelomgeving voor Windows waarmee studenten applicaties kunnen bouwen in talen zoals C#, C++, Python, JavaScript, TypeScript, ....
De IDE bevat een krachtige code‑editor, ingebouwde foutopsporing, grafische ontwerpers, compilers en geïntegreerde Git‑tools voor versiebeheer.
Dankzij de workload‑gebaseerde installatie kunnen studenten precies de onderdelen installeren die ze nodig hebben, zoals .NET‑desktopontwikkeling, webontwikkeling, ....

1. Downloaden van Visual Studio Community

  • Ga naar de officiële Microsoft‑website om Visual Studio te downloaden.
  • Zoek op de website naar Download Visual Studuo en selecteer de versie Community.
  • Het bestand wordt automatisch gedownload en komt in je downloadmap terecht. (VisualStudioSetup.exe).

2. Installatie uitvoeren

  • Open het gedownloade bestand (VisualStudioSetup.exe).
    Geef eventueel toestemming dat de app wijzingen mag aanbrengen aan het apparaat.
  • Na eventuele toestemming krijg je eventueel onderstaand scherm dat er nog extra zaken moet geïnstalleerd worden.
    Indien je dit niet krijgt, geen probleem, dan is al het nodig al geïnstalleerd.
  • Nadat de eventueel nog nodige software is geïnstalleerd, krijg je een scherm te zien waar je Workloads kan installeren.
    Klik hier niet direct op Install.
    • Vink in het midden van het scherm .NET desktop development aan.
      • In de latere OPO's gaan we ook nog gebruik maken van .Net multi platform App UI development, ASP.NET and web developent, Data storage and processing.
    • In het rechterscherm vink je volgende zaak uit
      • Github Copilot
      • .NET Copilot Skills
      • Github Copilot modernization
    • Klik nu op Install.
  • Visual Studio Community wordt met de ingestelde gegevens geïnstalleerd.
  • Als alles geïnstalleerd is, krijg je onderstaand scherm en kan je dit afsluiten.
    • >

3. Controle installatie

  • Zoek tussen de apps op je computer naar Visual Studio
  • Je krijgt de melding om in te loggen met een account.
    Selecteer hier Skip and add accounts later.
  • Ja kan Visual Studio instellen naar je persoonlijke voorkeuren
    • Development settings: kies hier voor Visual C#.
    • Choose your color theme: dit mag je zelf kiezen.
    • Klik hierna op Start Visual Studio.
  • Klik op onderstaand scherm rechts onderaan op Continue without code
  • Als je onderstaand scherm te zien krijgt, of iets gelijkaardigs, is alles correct geïnstalleerd en kan je Visual Studio afsluiten.
