Installatie van SQL Server

SQL Server is een volledige SQL‑server voor lokaal gebruik.

1. Downloaden van SQL Server Express

  • Ga naar de officiële Microsoft‑website om sql server te downloaden.
  • Zoek op de website naar Get started with SQL Server on-premises or in the cloud.
  • Download het installatiebestand bij de versie SQL Server 2025 Express.
  • Je zal in je Downloadsmap het gedownload bestand zien staan (SQL2025-SSEI-Expr.exe).

2. Installatie uitvoeren

  • Open het gedownloade bestand (SQL2025-SSEI-Expr.exe).
    • Geef eventueel toestemming dat de app wijzingen mag aanbrengen aan het apparaat
  • Kies Download Media installatie.
    • Kies als taal: English
    • Kies als package: Express Core
    • Klik op Download
    • Je zal een melding krijgen dat het downloaden is gelukt en klik op Open folder
  • In de Downloads map zal je het bestand zien staan die SQL Server zal installeren (SQLEXPR_x64_ENU.exe).

3. Installatie van SQL Server

  • Open het bestand (SQLEXPR_x64_ENU.exe).
  • Kies voor New SQL Server standalone installtion or add features to an existing installation
  • Accepteer de licentie overeenkomst en klink op Next
  • Vink automatische updates niet aan.
  • Install Rules: Als je op onderstaand scherm een warning krijg bij Windows Firewall is dit niet erg, al de rest moet wel een passed geven
  • Azure Extension for SQL Server vink je uit.
  • Features: Alles mag hier blijven staan of vink eventueel LocalDB aan
  • Configuratie van de Instance, gaan we de instance aanpassen naar VIVES
  • Bij de Server Configuration mag alles blijven staan en moet er niets aangepast worden
  • Bij de Database Engine Configuration kiezen we voor Mixed Mode
    Als paswoord nemen we Vives2627?
    Indien er niets bij SQL Server administrator staat, mag je op Add Current User klikken
  • SQL Server wordt met de ingeslde gegevens geïnstalleerd.
  • Als alles geïnstalleerd is, krijg je een overzicht op het einde alsook dat alles geslaagd is en klik op Close
  • Je zal terug het eerste scherm te zien krijgen
