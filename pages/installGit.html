Installatie van Git

In deze handleiding installeren we Git op Windows en configureren we Git zodat je het vanuit Visual Studio Code en PowerShell kunt gebruiken.
Git en GitHub zijn niet hetzelfde: Git is het programma op je computer voor versiebeheer. GitHub is het online platform voor repositories.

1. Controleer eerst of Git al geïnstalleerd is

  • Open PowerShell of de terminal in Visual Studio Code.
  • Voer uit: git --version
  • Als je bijvoorbeeld git version 2.x.x.windows.x ziet, is Git al geïnstalleerd. Ga dan rechtstreeks naar Git configureren (vanaf stap 14).
  • Als Windows meldt dat git niet herkend wordt, volg dan de installatie hieronder.

2. Git downloaden

  • Open de officiële Git-pagina voor Windows.
  • Voor de meeste studenten met Windows 11 kies je Git for Windows/x64 Setup.

3. Installer starten

  • Open het gedownloade .exe-bestand.
  • Windows kan vragen: Do you want to allow this app to make changes to your device?
  • Klik op Yes.

4. Installatielocatie

  • Bij Select Destination Location mag je de standaardlocatie behouden (bijvoorbeeld C:\Program Files\Git).
  • Klik op Next.

5. Components

  • Bij Select Components behouden we de standaardinstellingen.
  • Klik op Next. Je hoeft hier niets speciaal aan te passen.

6. Start Menu

  • Bij Select Start Menu Folder behoud je Git.
  • Klik op Next.

7. Kies een eenvoudige editor

  • Je krijgt het scherm Choosing the default editor used by Git.
  • Omdat we in deze opleiding Visual Studio Code gebruiken, kies je indien beschikbaar: Use Visual Studio Code as Git's default editor.
  • Als Visual Studio Code daar niet beschikbaar is, mag je bijvoorbeeld Notepad gebruiken.
  • Voor beginners is Vim niet aangeraden, omdat het afsluiten en bedienen daarvan in het begin onnodig verwarrend kan zijn.

8. Standaardbranch instellen op main

  • Bij Adjusting the name of the initial branch in new repositories kies je: Override the default branch name for new repositories.
  • Vul in: main.
  • Zo beginnen nieuwe repositories standaard met een branch genaamd main.

9. Git beschikbaar maken in PowerShell en VS Code

  • Bij Adjusting your PATH environment kies je: Git from the command line and also from 3rd-party software.
  • Dit is belangrijk omdat we Git ook vanuit PowerShell, VS Code en andere developmenttools willen gebruiken.

10. OpenSSH

  • Als je het scherm Choosing the SSH executable krijgt, behoud je: Use bundled OpenSSH.
  • Klik op Next.
  • We gebruiken GitHub-authenticatie voorlopig via HTTPS. SSH komt later terug voor Linux-servers.

11. Overige instellingen

  • Voor de overige installatieschermen mag je de standaardinstellingen behouden (HTTPS transport, line endings, terminal emulator, git pull behaviour, credential helper, extra options).
  • Klik telkens op Next tot je bij Install komt.
  • Je hoeft deze opties voor deze opleiding niet afzonderlijk te wijzigen.

12. Git installeren

  • Klik op Install.
  • Wacht tot de installatie voltooid is.
  • Daarna klik je op Finish.

13. Terminal opnieuw openen

  • Sluit PowerShell en/of Visual Studio Code volledig af.
  • Open daarna opnieuw een terminal.
  • Voer uit: git --version
  • Je moet nu een Git-versie zien.

14. Je naam configureren

  • Git moet weten wie commits maakt. Gebruik je echte voor- en achternaam.
  • Bijvoorbeeld: git config --global user.name "Voornaam Achternaam"
  • Dus bijvoorbeeld: git config --global user.name "Jan Janssens"

15. Je VIVES-e-mailadres configureren

  • Gebruik je officiële @student.vives.be-e-mailadres.
  • Bijvoorbeeld: git config --global user.email "voornaam.achternaam@student.vives.be"
  • Dit e-mailadres moet ook aan je GitHub-account gekoppeld en geverifieerd zijn, zodat GitHub je commits correct aan je account kan koppelen.

16. main instellen

  • Voer ook uit: git config --global init.defaultBranch main
  • Hierdoor gebruikt Git main als standaardbranch bij nieuwe repositories.

17. Controle

  • Voer uit: git config --global --list
  • Controleer minstens:
    • user.name=...
    • user.email=...@student.vives.be
    • init.defaultbranch=main
