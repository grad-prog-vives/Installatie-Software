Installatie van SQL Server Management Studio (SSMS)

Voor het beheren van databases, uitvoeren van queries en werken met stored procedures.

1. Downloaden van SSMS

  • Je had op het einde van het installeren van SQL Server terug het starscherm.
    Selecteer daar Install SQL Server Management Tool
  • Je wordt doorverwezen naar een internetpagina.
    Bovenaan zal je zien staan SQL Server Management Studio 22-installatieprogramma downloaden
  • Je zal in je Downloadsmap het gedownload bestand zien staan (vs_SSMS.exe).

2. Installatie uitvoeren

  • Open het gedownloade bestand (vs_SSMS.exe).
    Geef eventueel toestemming dat de app wijzingen mag aanbrengen aan het apparaat.
  • Na eventuele toestemming krijg je eventueel onderstaand scherm dat er nog extra zaken moet geïnstalleerd worden.
    Indien je dit niet krijgt, geen probleem, dan is al het nodig al geïnstalleerd.
  • Je verandert niets aan deze instelling, en laat alles uitgevinkt staan. En je klikt op Install.
  • Op het einde van de installatie krijg je een melding dat de installatie is voltooid en start de computer opnieuw op.

3. Controle installatie

  • Zoek tussen de apps op je computer naar SQL Server Management Studio 22
  • Je krijgt de melding om in te loggen met een account.
    Selecteer hier skip and add accounts later. Indien je onderstaande melding krijgt, selecteer hier no.
  • Je krijgt onderstaand scherm in in te loggen.
    Je merkt dat er hier nog niets ingevuld is. Pas aan met volgende instellingen
    • Selecteer bovenaan Browse.
    • Selecteer onder Local de instance VIVES met ervoor de naam van je computer.
    • User name: sa
    • Password: het paswoord van tijdens de installatie. Standaard Vives2627?
    • Encrypt: Optional
    • Trust Server Certificate vink je aan.
    • Klik op Connect.
  • Als alles goed gaat, krijg je nu het scherm dat SSMS opgestart is.
