Installatie van SQL Server Management Studio (SSMS)

Voor het beheren van databases, uitvoeren van queries en werken met stored procedures.

installatie

  • Download SSMS via de link op de SQL Server‑installatiepagina.
  • Installeer SSMS met de standaardinstellingen.
  • Start SSMS en maak verbinding met (local) of localhost.

4. Controle

  • Open SSMS en controleer of de server draait.
  • Maak een testdatabase aan via New Database.

5. Tips

  • Gebruik de Developer Edition voor alle oefeningen.
  • Noteer het wachtwoord van de sa‑gebruiker veilig.
  • Installeer ook Azure Data Studio als alternatief.
