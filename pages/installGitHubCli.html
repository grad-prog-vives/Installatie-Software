GitHub CLI installeren en aanmelden

Git is het programma git. GitHub CLI is het programma gh.
Met GitHub CLI kun je GitHub vanuit de terminal gebruiken en je gemakkelijk authenticeren.
GitHub ondersteunt op Windows installatie via WinGet.

1. GitHub CLI installeren

  • Open PowerShell.
  • Voer uit: winget install --id GitHub.cli --source winget
  • Bevestig indien Windows hierom vraagt.

2. Terminal volledig opnieuw openen

  • Na installatie moet je de terminal volledig sluiten.
  • Open daarna een nieuwe PowerShell- of VS Code-terminal.
  • Een nieuwe tab in een reeds geopende Windows Terminal kan onvoldoende zijn nadat PATH werd gewijzigd.

3. Installatie controleren

  • Voer uit: gh --version
  • Je moet een GitHub CLI-versie zien.

4. Aanmelden

  • Voer uit: gh auth login

5. Kies GitHub.com

  • Je krijgt een vraag zoals: Where do you use GitHub?
  • Kies GitHub.com.

6. Kies HTTPS

  • Bij What is your preferred protocol for Git operations? kies je HTTPS.
  • We gebruiken voorlopig HTTPS voor GitHub.

7. Git ook authenticeren

  • Als je gevraagd wordt: Authenticate Git with your GitHub credentials? kies je Yes.
  • Als je HTTPS kiest en dit bevestigt, kan GitHub CLI je Git-credentials mee configureren.

8. Aanmelden via browser

  • Kies Login with a web browser.
  • Er verschijnt een tijdelijke code, bijvoorbeeld ABCD-1234.
  • De code in jouw terminal zal anders zijn.

9. Open de browser

  • Druk indien gevraagd op Enter.
  • De browser opent GitHub.
  • Controleer zeer goed met welk GitHub-account je in de browser bent aangemeld.
  • Het moet hetzelfde account zijn dat je voor je vakken gebruikt en waaraan je @student.vives.be-adres gekoppeld is.

10. Device code bevestigen

  • Als GitHub vraagt om de code in te voeren:
    • plak de code
    • klik op Continue
    • controleer het GitHub-account
    • autoriseer GitHub CLI.
  • Klik indien gevraagd op Authorize GitHub.

11. Controle

  • Ga terug naar PowerShell.
  • Voer uit: gh auth status
  • Je moet zien dat je ingelogd bent op github.com met je juiste username.

Verkeerd account gebruikt?

  • Controleer met: gh auth status
  • Ben je met het verkeerde account ingelogd? Voer uit: gh auth logout
  • Daarna opnieuw: gh auth login

Als Git nog steeds authenticatieproblemen geeft

  • Als je tijdens gh auth login niet gekozen hebt om Git mee te configureren, kun je uitvoeren: gh auth setup-git
  • Dit configureert Git om GitHub CLI als credential helper te gebruiken.

Eindcontrole Git + GitHub CLI

  • Deze twee commando's moeten werken: git --version en gh auth status.
  • Als beide correct zijn, is je lokale basisconfiguratie klaar.
