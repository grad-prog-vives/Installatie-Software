GitHub-account aanmaken

Voor deze opleiding gebruiken we GitHub met je officiële @student.vives.be-e-mailadres.
Heb je nog geen GitHub-account? Volg deze handleiding vanaf stap 1.
Heb je al een GitHub-account? Maak niet automatisch een tweede account. Ga naar het hoofdstuk Ik heb al een GitHub-account.

1. GitHub openen

  • Ga naar GitHub.
  • Klik rechtsboven op Sign up.
  • Of ga rechtstreeks naar GitHub Sign up.

2. Gebruik je VIVES-mailadres

  • Wanneer GitHub om een e-mailadres vraagt, gebruik je @student.vives.be.
  • Bijvoorbeeld: voornaam.achternaam@student.vives.be
  • Gebruik geen tijdelijk of ander schoolvreemd adres voor deze cursus.

3. Kies een wachtwoord

  • Maak een sterk wachtwoord.
  • Gebruik geen wachtwoord dat je ook voor je VIVES-account gebruikt.
  • Ga verder naar de volgende stap.

4. Kies een gebruikersnaam

  • GitHub vraagt je om een unieke username te kiezen.
  • Gebruik bij voorkeur iets herkenbaars en professioneel, bijvoorbeeld jan-janssens, jjanssens of janJanssensDev.
  • Minder handig voor een schoolomgeving: unknown-user-2026.
  • Je GitHub-username wordt later gebruikt in repositories en kan zichtbaar zijn voor de docent.

5. Account aanmaken

  • Volg de overige stappen van GitHub en maak het account aan.
  • De precieze signup-interface kan door GitHub veranderen.

6. E-mailadres verifiëren

  • GitHub stuurt een verificatiemail naar je @student.vives.be-adres.
  • Open je VIVES-mailbox.
  • Open de e-mail van GitHub.
  • Klik op de knop/link om je e-mailadres te verifiëren.
  • Zonder verificatie zijn bepaalde basisfuncties van GitHub beperkt.

7. Controle

  • Ga in GitHub rechtsboven naar je profielfoto.
  • Kies Settings en daarna Emails.
  • Controleer dat je @student.vives.be-adres als Verified staat.

Ik heb al een GitHub-account

  • Je hoeft normaal geen nieuw account te maken.
  • Gebruik je bestaande GitHub-account en voeg je VIVES-e-mailadres toe.
  • Ga naar: Profile picture → Settings → Emails.
  • Bij Add email address vul je je @student.vives.be-adres in.
  • Klik op Add. GitHub stuurt vervolgens een verificatiemail.
  • Open je VIVES-mailbox en klik op de verificatielink van GitHub.
  • Controleer daarna opnieuw Settings → Emails: je schoolmail moet als Verified staan.

Als je schoolmail al gebruikt wordt

  • Krijg je een melding dat @student.vives.be al aan een ander GitHub-account gekoppeld is?
  • Maak dan niet nog meer accounts.
  • Waarschijnlijk heb je al eerder een GitHub-account met dat adres gebruikt.
  • Probeer op GitHub Forgot password? en herstel eerst het bestaande account.
  • Vraag indien nodig hulp aan de docent.

Heel belangrijk: gebruik één account

  • Gebruik in al je vakken steeds hetzelfde GitHub-account voor:
    • GitHub.com
    • GitHub CLI
    • Classroom 50
    • assignment repositories
  • Anders kun je problemen krijgen waarbij bijvoorbeeld Classroom 50 account A gebruikt en GitHub CLI account B. Dat willen we vermijden.
